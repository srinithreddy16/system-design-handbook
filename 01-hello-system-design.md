# Hello System Design

## Why system design

A system is a set of parts that work together for a purpose. Some systems already exist. The digestive system and the respiratory system were discovered, not built. Their parts can be altered only a little, and only with something like surgery.

Systems in software are different. Engineers build them, so the system and its parts can be chosen for the requirement, then changed as requests, load, and traffic change.

## System

Two or more components working toward the same purpose. An application can serve more than one use case, and the common goal stays the same.

```
system = components + common goal
```

## Design

Design is choosing those components and shaping them around the goal that comes out of requirement analysis. The components and the goals for real applications come later in the series.
