# Functional Requirements

## Functional Requirements

### What are they?

All the features and actions a user can take in the application. If you list every feature you are building, that list is your functional requirements.

### Example: Amazon (e-commerce)

A user should be able to:

- Register
- Log in
- View products
- Search products
- Filter products
- Add a product to the cart
- Apply coupon codes for discounts
- Place an order
- Make a payment
- Track the order

This applies to any e-commerce app, not just Amazon.
